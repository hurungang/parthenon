About the System entry

The System entry represents Parthenon's built-in platform tools. It is shown only once, is not editable or deletable, and cannot be synced from this view.

The Control Center entry (cc) is the platform-provisioned management integration: system-managed, sessionless, and hidden entirely from roles without integration::control_center:read. It hosts the cc____* management tools.

Agent Client

Tenant-managed access grants bound to one agent type. A client is not an agent identity — it can only invoke the agent type's input interface (conversation turn or typed submit), never tools or the MCP hub.
🔑 Clients
💬 Widget Preview (End User)
🖥️ Server-Side Flow (Secret)
ClientAgent TypeCredentialAllowed OriginsRate LimitStatusActions
Scoping. A client credential reaches only the target agent type's input interface. The invoked agent type always runs with its own identity + role. Publishable clients require at least one allowed origin (wildcards like https://*.acme.com supported); incoming request origins are detected automatically from the browser/deployment — there is no user-editable origin field. All invocations are audited, never the credential value.

● No session

Stateful conversation flow

1. Start session → POST /integrate/conversations

2. Messages → /messages share the same conversation context (like Control Center chat). There is no one-shot chat.

3. End session → /end

Replies render with format detection: markdown incl. tables and pretty-printed JSON. Guardrail/timeout failures surface as error turns, never an endless spinner.

Origin (automatic)

https://acme.com

Sent automatically by the browser; checked against the client's allowed origins.

Typed request/response — Python SDK (secret client)

secret · phn_cl_sk_…
from parthenon import Client

client = Client(secret_key="phn_cl_sk_…")      # server-side only
result = client.invoke("inbox-triage", input={
    "email_body": "I ordered a laptop two weeks ago but it arrived damaged. I want a refund."
})
print(result.status)      # "valid"
print(result.output)      # typed AgentOutput
Simulated — typed responses include validation status with raw-output fallback.
Optional dual identity: a secret client may pass its end user's identity when the third party and tenant share an identity provider — server-to-server only, validated and tenant-matched. Identity tokens never reach a browser.
