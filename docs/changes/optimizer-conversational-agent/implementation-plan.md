# Implementation Plan: optimizer-conversational-agent

## Overview

Make optimization an **optimization-mode conversation on the subject agent type itself** (the avatar model): an ordinary `ConversationSession` on that agent type with `channel = "optimization"`, running the optimization mission with the agent's own identity, role and tool grants — no seeded optimizer agent, no new identity or role, no scope column. The operator watches the work, answers in-chat questions, and can approve **one** precisely listed live test that runs once under the agent's own identity, while replay stays the default and the optimizer model stays a tenant-scoped setting that falls back to the plan-authoring model.
