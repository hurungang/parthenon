Root agent at depth 0. Each hop is one delegated agent. Attempts past the configured depth are blocked and recorded against this limit.
Effect of the change
Before
Whatever value was configured, the platform stopped any chain after one delegated level — a hidden cap of two levels that nobody could see or configure. Agents could not delegate onward, and the log reported a fixed maximum that contradicted this screen.
Now
Configured depth 3 is the only limit. A root agent plus 3 delegated levels may run, and the execution log reports 1 / 3 style depth against this value.
