Unified Topology Diagram — for ALL agent types This Epic

The agent preview now renders the same PanelTopologyCanvas component used in the Agent Management Panel — for conversational AND typed agents. Typed agents additionally keep their plan step list (with script links) and the Regenerate plan button below the canvas; the old plan-based topology diagram is gone. Input/output slots show the editor dialog's labels — None, Conversation, Auto — as solid nodes; only genuinely unfilled slots stay dashed placeholders. Zoom (0.5×–3×) caps font size at 1.6×, so zooming reveals more content instead of magnifying text.

    Zoom & Font-Cap Behaviour

    Fullscreen zoom (0.5×–3×, step 1.2) — fonts stop growing at the 1.6× cap (TOPOLOGY_MAX_FONT_SCALE).
    🔍

    Zoom reveals MORE CONTENT — not bigger text

    Past the 1.6× cap, drawn font sizes shrink by cap / zoom so on-screen glyph size plateaus while the visible world region keeps expanding. Width-fitted labels fit more characters before ellipsis, and more nodes come into view. Try the fullscreen button (⛶) on the canvas below, then zoom past 160%.

    Data Analyst — Topology

    Watch the zoom badge turn amber past 160% — text size stops, content keeps growing.
    viewFontZoom = 1.6 (fullscreen only)
