Agent Management Panel

One canonical topology canvas. Bound-but-unresolved entities render a spinner and “Loading…” — never their raw id.

Agent Topology ● LIVE

Three distinct states

never conflated
⏳ Pending
The reference request is in flight and the name is not cached. Node shows a spinner in the icon slot plus Loading…. Geometry does not change.
❓ Genuinely missing
The request completed but the referenced row is absent. The historical raw-id fallback is kept — no spinner.
▫️ Deliberately empty
No binding at all (or an intentional contract state). Dashed placeholder — and “No tools” only after tools resolve.
