Agent Types

Configure agent types with curated SOP and skill bindings. Each agent type binds an ordered list of SOPs and skills drawn from its role.
💡
New: Multi-SOP Binding
Agent Types now support binding multiple SOPs and skills as an ordered list — instead of a single "Primary SOP." This mirrors how SOPs bind skills and gives you precise control over which capabilities each agent type receives as context.

What this prototype demonstrates

agent-type-multi-sop-binding

Click "Edit" on any agent type to open the editor drawer and explore the new binding model:

  • SOP/Skill Binding Section — Ordered list of bindings with type selector, dropdown picker, and remove button
  • Drag-to-reorder — Use drag handles or up/down arrow buttons to reorder bindings
  • Role-based filtering — Change the role and watch the available SOPs and skills update in dropdowns
  • Validation feedback — Try adding a duplicate binding or switching to a role that doesn't have access to see inline errors
  • Plan Preview tab — See how the curated binding list feeds into the AI-generated implementation plan
