Decision Tools

User-defined tools that route structured snap judgments to a System One model. They behave exactly like system tools — auto-described, grantable via roles, invocable by skills and MCP clients.

🏢
Tenant-contained naming. Tool names are unique within your tenant (acme-corp) only. Tenant B can define its own tool_a; the platform resolves decision____tool_a within the caller's tenant. All lookups, permissions, and invocations are tenant-scoped.

System One Configuration

      
Configure fast, structured decision-making models (TypeSafe AI "Jev"). Credentials are encrypted at rest and never returned in plaintext.


      

        ℹ️
        
System One models evaluate predefined typed questions against a state and return structured answers — typed values, probability distributions, and confidence — without generating text. All calls originate from Control Center-managed flows; agents never hold credentials.
