Sessions — slack-tools

OAuth token state for every session on this server. An unrecoverable token refresh marks the session Needs re-authentication and offers a re-auth action instead of silently breaking the agent.
💡
Prototype scenario — four sessions on the same server show the three token states:
• Slack OAuth — healthy, Valid (34h) with a green refresh action.
• Slack OAuth — Reporting — Expired, but the refresh token is still valid so a refresh is offered.
• Slack OAuth — Incident Channel — ⚠ Needs re-authentication. Hover the status chip for the stored failure reason, then click the red re-auth button.

Optimized Plan

The optimized plan tab of an Agent Type. A failed verification persists its reason on the plan and shows it above the content; retiring is never a silent no-op.
