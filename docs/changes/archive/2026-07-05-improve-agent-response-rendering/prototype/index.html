🔍 How ContentRenderer Works in Chat Mode

1. HTML Detection

containsHtmlTags() checks the content string for HTML tags using regex /<[a-zA-Z][^>]*>/m. False positives (e.g. comparison operators x < 5) are avoided.

2. Render Path

HTML detected: Sanitized via DOMPurify, rendered with dangerouslySetInnerHTML. No HTML: Rendered as Typography whiteSpace='pre-wrap' for preserved whitespace.

3. Maximize

MaximizableContent wraps the content in a position: relative container. An IconButton with OpenInFullIcon is positioned top-right. Click opens MUI Dialog (95vh, fullWidth).

Integration points: ConversationDialog.tsx (line ~702): <MaximizableContent title="Agent Response"><ContentRenderer mode="chat" content={msg.content} /></MaximizableContent> for agent messages. AgentJobPage.tsx uses the same pattern in both the live chat and conversation history views.

🔍 How ContentRenderer Works in Execution Detail (mode="auto")

1. Extract Text

extractResultText() extracts plain text from content block arrays or plain strings. Content blocks are concatenated with double newlines.

2. Detect Format

containsHtmlTags() checks for HTML markup. Only applies to auto output type.

3. Render

HTML: Sanitized (DOMPurify) → direct render, bypassing markdown. No HTML: Goes through simpleMarkdownToHtml() as before.

4. Wrap

All output branches (auto, markdown, typed) are wrapped in MaximizableContent for the maximize affordance.

Integration point: OutputTypeResultTab.tsx — the auto branch uses <ContentRenderer mode="auto" content={autoExtractedText} /> wrapped with MaximizableContent. Markdown output type also uses MaximizableContent. Typed outputs (schema-validated) are unaffected by HTML detection. Raw JSON fallback (when autoExtractedText is null) is rendered as syntax-highlighted JSON.
