Agent Client

Tenant-managed access grants bound to one agent type. A client is not an agent identity — it can only invoke the agent type's input interface.
ClientAgent TypeCredentialAllowed OriginsRate LimitStatus
🔐 Scoping: a client credential reaches only the target agent type's input interface — a conversation turn (conversational types) or a typed submit (typed types). It cannot list or call tools, cannot reach the MCP hub, and never authenticates as an agent identity. All invocations are audited (never the credential value itself).

How state flows

1. Start session → POST /integrate/conversations returns a conversation id.

2. Each message goes to POST /integrate/conversations/{id}/messages and shares the same conversation context — like the Control Center chat.

3. End session → POST /integrate/conversations/{id}/end. There is no one-shot chat.

Replies render with format detection: markdown (incl. tables) and pretty-printed JSON.

Origin (automatic)

https://acme.com

Sent automatically by the browser — there is no user-editable origin field. Requests from origins outside the client's allowlist are rejected.

Server-Side Invocation — Secret Client

A third-party backend invokes a typed agent as "submit input → receive validated typed response". The secret credential never leaves their servers.

Python SDK — typed request/response

secret · phn_cl_sk_… 
from parthenon import Client

client = Client(secret_key="phn_cl_sk_…")      # server-side only
result = client.invoke("inbox-triage", input={
    "email_body": "I ordered a laptop two weeks ago but it arrived damaged. I want a refund."
})
print(result.status)      # "valid"
print(result.output)      # typed AgentOutput
Simulated — responses are delivered as validated, typed results.
🔐 Optional dual identity: when the third party and the tenant share an identity provider, a secret client may pass its end user's identity — server-to-server only, validated and tenant-matched before use. Identity tokens are never issued to or stored by the third party's browser.
