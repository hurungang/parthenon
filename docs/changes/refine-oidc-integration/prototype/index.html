Independent Providers

User and agent identity providers are completely independent. You can use the same provider for both, or different ones. Changing one does not affect the other. Agent identity tokens are centrally managed by Control Center and never exposed to agent runtimes.

Super Admin Configuration

When enabled, the super admin can log in with local credentials regardless of OIDC status. When disabled, only OIDC-authenticated users can access the platform.
⚠️ Warning: Super Admin Disabled

With super admin disabled, you can only log in via OIDC. If the OIDC provider becomes unreachable, you will need to re-enable super admin via environment variable (PARTHENON_SUPER_ADMIN_ENABLED=true) or direct database access.

ℹ️ Super Admin is Enabled

The super admin account provides a fallback in case of OIDC misconfiguration. In production, disable this once OIDC authentication is confirmed working.

⚠️ Disable Super Admin?

Are you sure?

Disabling the super admin means:

  • Only OIDC-authenticated users can access the platform
  • If the OIDC provider becomes unreachable, you may be locked out
  • To re-enable, you'll need to set PARTHENON_SUPER_ADMIN_ENABLED=true or modify the database directly

Ensure at least one OIDC user has been assigned the admin role before proceeding.
