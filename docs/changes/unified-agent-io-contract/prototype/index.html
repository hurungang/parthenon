Register a data type to define what an agent accepts or returns — a passenger record, a booking confirmation, a flight request. Typed agents cannot be saved without one.

① One level of child data types. A field may reference another data type as a child, once or as a list. A data type that already references a child cannot itself be used as a child — and a data type already used as a child cannot reference one; the pickers disable those options and explain why. This keeps schemas reviewable and predictable.
