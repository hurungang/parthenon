Acceptance criteria — structural & visual

  • ✓#1–7Sidebar has exactly 4 top-level entries (Dashboard, Agents, Integrations, System). Agents has 9 children (Agent Trails consolidates Conversation History, Executions, and Results), Integrations 2 (locked open; Notifications consolidates Channels, Groups, Logs), System 3.
  • ✓#6No routes removed, no routes duplicated — every existing capability remains reachable at exactly one location.
  • ✓#8Sidebar width is 256px on desktop (unchanged mobile drawer behavior).
  • ✓#9Item font size is 13.5px; group labels are 10px uppercase with 1px letter-spacing for a distinct typographic weight.
  • ✓#10Icons render at 16px inside a 20px flex slot, vertically aligned to text.
  • ✓#11–12Active item uses the pill shape (right-side border-radius: 0 24px 24px 0), background #E3F2FD, text #1976D2, weight 600. Hover uses a subtle neutral background — distinct from the active pill.
  • ✓#13–14Group headers expand/collapse on click; when a child is active, the group label adopts the active color treatment so operators see "I am inside Agents".
  • ✓#15–20i18n keys, mobile drawer, CRUD refresh, permission gating, and keyboard navigation are all preserved (no behavior changes — this is a presentation-only delta).
