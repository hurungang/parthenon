# Contributing to Parthenon

Parthenon welcomes community contributions.

## Before you contribute

Open an issue or discussion for significant changes so the scope and direction
are aligned before implementation.

## License for contributions

Parthenon uses an explicit Contributor License Agreement process to back the
relicensing terms below.

Before a pull request can be merged, each contributor must:

1. Read [CLA.md](CLA.md).
2. Open or update a pull request.
3. If prompted by the CLA check, reply on the pull request with the exact
   acceptance text shown in [CLA.md](CLA.md).

The CLA workflow records that acceptance against your GitHub account for future
pull requests.

By signing the CLA and submitting a contribution to this repository, you agree
that:

1. Your contribution is provided under the repository's open source license,
   GNU Affero General Public License version 3.0 or any later version.
2. You represent that you have the right to submit the contribution under those
   terms.
3. You grant the project maintainers and copyright holders a perpetual,
   worldwide, non-exclusive right to use, reproduce, modify, sublicense, and
   relicense your contribution as part of Parthenon under other licenses,
   including commercial licenses.

If these terms do not work for you, do not submit a contribution until a
separate written agreement is in place.

## Development notes

Use the repository documentation and scripts in the root README to run the
stack locally and validate your changes before opening a pull request.

When you open a pull request, complete the PR template checklist and ensure the
CLA status check is green before requesting review.
