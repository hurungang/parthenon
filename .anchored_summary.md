## Goal
- Fix delegation UI to show one consolidated entry per delegation with status transitions (delegating→waiting→completed) and inline sub-agent execution log, plus fix backend timeout error.

## Constraints & Preferences
- Delegation events must merge into a single inline entry in the execution log, not 3 separate entries
- Only one "DELEGATION" entry per delegation, with status chip showing final state
- Expanded timeline must show intermediate delegation events (started, waiting, resumed) from the parent and sub-agent execution entries
- "View Full Execution Log" button must open sub-agent's AgentExecutionDetailsDialog
- Label "DELEGATION RESUMED" must display as "COMPLETED"
- All existing tests must continue to pass
- Sub-agent log entries fetched via API in StepRow when delegation entry is expanded
- Sub-agent log entries must poll/stream while delegation is active, so new entries appear in real-time
- "View Full Execution Log" button must appear for both delegation code paths — non-waiting dispatch (where `receiver_session_id` is in `delegation_waiting`) and blocking/TaskAgentLoop path (where `receiver_session_id` is only available in `a2a_result`)

Fix: include it in `delegation_resumed`/`timeout`/`failed` from `a2a_result` after the call returns.
- Delegation timeout root cause (HTTP 422 from timeout_seconds=300 > 120 cap) fixed by clamping in `comm_hub_client.py`
