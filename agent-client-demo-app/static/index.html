Parthenon — Agent Client Demo

Two integration modes: server-side secret proxy, or a real browser widget with a publishable key.
Server-to-server: the demo backend calls the gateway with your secret. Origin is irrelevant here — the secret is the authentication.
The browser calls the gateway directly with your publishable key — the browser sets Origin automatically (unspoofable). Add this page's origin (http://localhost:7002) to the client's allowed origins.
